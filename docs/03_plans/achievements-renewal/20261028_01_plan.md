# 実績を「目指したこと」と「数値」で見せる刷新

> 棚卸しの結果（`docs/02_research/2026_10/achievements-inventory.md`）と、Design キャンバスのモックアップをもとに実装した内容をまとめたものです。

## 方針

- 実績は「何を作ったか」ではなく、「何を目指したか」と「どれだけ変わったか」で見せる
- 数値には必ず種類を付ける。実測（●）・試算（○）・目標（破線の○）。値が分からない数値は載せない
- 数値は実績データ（`src/data/works.ts`）にだけ書き、トップ・経歴・スキルシートはそこから引く

## データ

| ファイル | 役割 |
| --- | --- |
| `src/types/works.ts` | `Work` に区分・期間・目指したこと・課題・打ち手・数値（`Impact`）・根拠を持たせる |
| `src/data/works.ts` | 実績 36 件。区分は客先案件・社内ツール・人材育成・受託・個人開発の 5 つ |
| `src/data/highlights.ts` | トップ・経歴・About に並べる代表的な数値。実績の数値を slug と位置で参照する |
| `src/data/profile.ts` | 経歴。まとまりごとに実績の slug を並べ、題名・期間・見出しの数値は実績から引く |
| `src/data/skill-sheet.ts` | 案件ごとの担当工程・技術。目指したこと・数値・期間は紐づく実績から引く |

`Impact` の主な項目は次のとおりです。

| 項目 | 例 |
| --- | --- |
| `label` | 1 回の注文時間（平均） |
| `before` / `value` / `unit` | `5分` → `1` `分` |
| `kind` | `measured`（実測）/ `estimated`（試算）/ `target`（目標） |
| `note` | 3ヶ月、タスクによる最大値 |
| `bars` | 詳細ページで前後を棒で比べるときの値 |

## ページ

| ページ | 変更 |
| --- | --- |
| トップ | About の指標を実測の数値 4 つに変更。展示室は Agora・社内 OSS を含む 4 件に、目指したことと数値を添える。その他は実測の数値がある実績を区分の順に 6 件 |
| 実績一覧 | 区分のタブ、「実測の数値がある実績だけ」の絞り込み、凡例。区分の順・新しい順に並べる |
| 実績詳細 | 成果 → 目指したこと → 打ち手 → 数値（前後の比較）→ 根拠と技術。ある節にだけ漢数字を振る |
| About | 「取り組んでいること」（AI 駆動開発・内製・育成）を追加。経歴は要約と代表的な成果だけにする |
| 経歴詳細 | キャリアハイライトを実測の数値に変更。仕事ごとの行に見出しの数値を添える |
| スキルシート | 区分・目指したこと・成果の数値を追加。担当工程に「導入支援・教育」を追加 |

画面の画像がない実績は、`WorkFigure` で図を描きます。NDA に配慮した客先案件は成果の数値を大きく置き、それ以外は題名を置きます。

## 数値を足すとき

`src/data/works.ts` の該当する実績の `impacts` に追記します。先頭の数値がカードや一覧の見出しになります。次の数値はまだ値がなく、載せていません。

| 実績 | 数値 |
| --- | --- |
| Agora | oVice の利用人数・月額単価からの削減額（試算） |
| TB パレット | 面談記録の登録時間、表示速度の変化 |
| TB Force | 名刺 1 枚の登録時間（手入力と撮影の比較） |
| Falcon Auto Review | 課題 1 件のレビュー時間 |
| AI-DLC 導入 | リードタイム、AI の利用コスト |
| AD/ADAS | デプロイの所要時間、短縮期間の人月換算 |
