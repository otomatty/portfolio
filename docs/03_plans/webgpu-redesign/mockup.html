Mockup notes · v2

このモックアップについて

コンセプトは「枯山水と円」です。旧トップの「重なる2つの円」を庭石に見立て、そのまわりに砂紋を引きます。七宝・青海波・円環ナビなど、ほかの模様もすべて円の組み合わせだけで作図しています。色は現行ダークの深緑と金だけにし、余白を多くとります。

v1 からの変更

  • カラーは暗めの緑とゴールドを基調に背景は現行ダークの hsl(136 31% 8%)、金は現行パターンの #D0A900 と #987D00。ライトテーマはなくし、この一色の世界に絞りました。
  • フォントをもっとシンプルに明朝をやめ、現行と同じ Inter と Noto Sans JP の2書体にしました。見出しは細め（300）にして字間を広くとっています。
  • 幾何学と和柄、数学的な美しさ、禅金粉をやめ、Hero は WebGPU で描く枯山水にしました。七宝と青海波は旧サイトの ShippoPattern・SeigaihaPattern と同じ作図を Canvas 2D で描き直しています。
  • 画像はモノクロにするだけ網点をやめ、写真はグレースケールにしました。実績の画面画像もモノクロで、カーソルを重ねたときだけカラーに戻ります。
  • 実績の見せ方を工夫12件を作成順に円周へ並べた「円環ナビ」と、大きなプレビューの組み合わせにしました。

  1. 1Hero：WebGPU の枯山水

    フラグメントシェーダで画面の全ピクセルの砂紋を計算します。石の外側の線は、円柱のまわりを流れる水の流線 ψ = y (1 − R² / r²) の等高線です。そのため、まっすぐな砂紋が石の手前で自然に分かれて回り込みます。石のまわりの同心円は、2つの円の外形から外周の円へ少しずつ形を変えます。

    読み込み時は、コンパスで2つの円を描いたあと、砂紋が石から外へ広がります。砂紋は9秒周期でわずかに呼吸し、カーソルを動かすと指でなぞったように砂紋がよけます。円の上を金の弧がゆっくり回るのは、旧 Hero の回転する弧を引き継いだものです。

    下のツールバーで WebGPU と Canvas 2D（静止した砂紋と回る弧）を切り替えられます。

  2. 2About：七宝の円窓

    七宝つなぎは、半径 r の円を格子点 (i·r, j·r)（i + j が偶数）に置くだけでできる模様です。丸窓の中でこの格子が4分で一回転し、カーソルの近くの円だけが明るくなります。数字は3つだけに絞りました。

  3. 3Works：円環ナビ

    12件の実績を作成した順に、上から時計回りに円周へ並べます。塗りの点が個人開発、輪の点が実務です。点や矢印、キーボードの ← → で選ぶと、針が回って右のプレビューが円形に切り替わります。種別で絞り込むと、対象外の点は薄くなって選べなくなります。1本の円で、件数・時系列・種別が同時に読めます。

  4. 4Profile：モノクロ写真

    写真はグレースケールにするだけにしました。背景が透過した写真なので、後ろに細い金の円を置き、月を背にした掛け軸のような構図にしています。

  5. 5Contact：青海波

    中心を半径の分ずらしながら同心円を重ねた青海波です。光の輪がゆっくり通り過ぎ、空いている所をクリックするとそこから波紋が広がります。

描画方式とフォールバック

要素描画非対応のとき止めるとき
Hero 枯山水WebGPU（全画面フラグメントシェーダ）Canvas 2D で砂紋を一度だけ計算し、弧だけを動かす画面外、タブ非表示。reduced-motion では静止1フレーム
七宝の円窓Canvas 2DCSS の ShippoPattern画面外、reduced-motion
円環ナビCanvas 2D と、点の上に重ねた <button>同じ順の一覧を SSR で出力選択を切り替えた約0.7秒だけ描画
青海波Canvas 2DCSS の SeigaihaPattern画面外、reduced-motion

実装の進め方

  1. 配色トークンを深緑と金に絞り、ライトテーマ用の値と ThemeToggle を外す
  2. src/lib/canvas/ に共通の描画ループ（DPR 上限 2、画面外とタブ非表示での停止、reduced-motion）をまとめる
  3. Hero を HeroGarden.tsx として client:idle の island にし、WebGPU → Canvas 2D の順にフォールバックさせる
  4. works.ts から円環ナビを組み、Achievements と AdditionalAchievements を置き換える
  5. 七宝・青海波を Canvas 化し、使わなくなった magicui コンポーネントを削除する。最後に Lighthouse CI で LCP と TBT を確認する
