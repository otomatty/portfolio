Mockup notes

このモックアップについて

コンセプトは「蒔絵（まきえ）」です。漆の深い緑に金粉を蒔くように、現行サイトの配色（深緑・クリーム・金）と和柄のモチーフはそのまま引き継ぎ、装飾を GPU で描く金粉に集約します。大きな動きは Hero の一か所だけに置き、ほかのセクションは Canvas 2D による控えめな表現に留めます。

箇所現行提案
HeroSVG と CSS で回る2つの円、中央揃えの見出し2つの円を WebGPU の金粉の軌道として描き直す。見出しは左揃え
アクセント色紫からピンクへのグラデーション文字金の単色に絞る
背景パターンmagicui の7種（FlickeringGrid・Shippo・Seigaiha・Dot・Grid・Ripple・Particles）WebGPU 1つと Canvas 2D 3つに統合
自己紹介Bento グリッド3つの数字と活動年表
注目の実績黒背景の全画面ビュー一覧とプレビュー
書体Inter・Noto Sans JP見出しは Shippori Mincho、本文は Noto Sans JP、数字とラベルは Geist Mono

  1. 1Hero：WebGPU の金粉フィールド

    compute shader で 65,536 粒（スマートフォンは 16,384 粒）の位置を毎フレーム更新し、インスタンス描画で点を打ちます。現行 Hero の「重なる2つの円」を粒子の軌道として引き継ぎ、カーソルの周りでは金粉が渦を巻きます。読み込み直後は画面全体に散った粒が約2.5秒で円に集まります。

    WebGPU に対応していないブラウザでは同じ動きを Canvas 2D の 4,000 粒で描き、OS の「視差効果を減らす」設定では静止した1フレームだけを表示します。

    下のツールバーで WebGPU と Canvas 2D を切り替えて比べられます。

  2. 2数字と活動年表：Canvas 2D

    Bento グリッドを、3つの数字と1本の年表に置き換えます。年表は works.ts の created_at と経歴の節目から描き、塗りの点が個人開発、輪の点が実務です。点にカーソルを合わせると作品名が出ます。同じ内容をリストとしても出力し、検索エンジンとスクリーンリーダーに渡します。

  3. 3Works：一覧とプレビュー

    作品を一覧で並べ、行にカーソルを合わせると右のプレビューが金のブロックを伴って切り替わります（Canvas 2D のクリップ描画、約0.5秒）。スマートフォンではプレビューを使わず、各行にサムネイルを表示します。

  4. 4Profile：網点のポートレート

    プロフィール写真を 8×8 の組織的ディザで網点にし、松の葉を金、人物を地の反対色で描き分けます。カーソルを重ねた円の中だけ元の写真が見えます。

  5. 5Contact：青海波

    現行の SeigaihaPattern を Canvas 2D で描き直し、光の輪がゆっくり通り過ぎます。空いている所をクリックすると、そこから波紋が広がります。画面外では描画を止めます。

実装の進め方

  1. src/lib/canvas/ に共通の描画ループをまとめる（requestAnimationFrame、DPR 上限 2、画面外とタブ非表示での停止、reduced-motion、テーマ色の取得）
  2. Hero を HeroField.tsx として client:idle の island にし、WebGPU → Canvas 2D → 静止画の順にフォールバックさせる
  3. デザイントークンを整理し、アクセントを金に一本化する。見出し用の明朝はサブセット化して自前でホストする
  4. 年表・Works・Profile・Contact を順に置き換え、使わなくなった magicui コンポーネントを削除する
  5. 既存の Lighthouse CI（.lighthouserc.json）で LCP と TBT が悪化していないことを確かめる
