# HTML Canvas / WebGPU によるデザイン刷新 モックアップと計画

> 本書は実装前の提案です。モックアップ（`mockup.html`）で方向性を確認したうえで、実装を別 PR に分けて進めます。

## 概要
コンセプトは「蒔絵（まきえ）」です。漆の深い緑に金粉を蒔くように、現行の配色（深緑・クリーム・金）と和柄のモチーフを引き継ぎ、装飾を GPU で描く金粉に集約します。大きな動きは Hero の一か所だけに置き、ほかのセクションは Canvas 2D による控えめな表現に留めます。

## モックアップの見方
`mockup.html` は `public/images/` の画像を相対パスで参照します。ポートレートは `getImageData` を使うため、`file://` ではなく HTTP で開いてください。

```sh
bunx serve .   # リポジトリ直下で起動し、/docs/03_plans/webgpu-redesign/mockup.html を開く
```

画面下のツールバーで、描画方式（WebGPU / Canvas 2D）、テーマ（自動 / ライト / ダーク）、注釈の表示を切り替えられます。

## 描画方式とフォールバック
| 要素 | 描画 | 非対応のとき | 止めるとき |
| --- | --- | --- | --- |
| Hero 金粉 | WebGPU。compute shader で 65,536 粒（狭い画面は 16,384 粒）を更新し、インスタンス描画 | Canvas 2D 4,000 粒 | 画面外、タブ非表示。`prefers-reduced-motion` では静止1フレーム |
| 活動年表 | Canvas 2D。`works.ts` の `created_at` と経歴の節目から描画 | 同じ内容の `<ol>` を SSR で出力 | ホバーとリサイズ時のみ再描画 |
| Works プレビュー | Canvas 2D（ブロック単位のクリップで約0.5秒のディゾルブ） | `<img>` | 切り替え中のみ |
| ポートレート | Canvas 2D（8×8 組織的ディザ、ホバー位置だけ実写） | `<img>` | ホバー中のみ |
| 青海波 | Canvas 2D | CSS 背景の静止画 | 画面外、`prefers-reduced-motion` |

## 実装ステップ
1. `src/lib/canvas/` に共通の描画ループをまとめる（requestAnimationFrame、DPR 上限 2、IntersectionObserver と `visibilitychange` での停止、reduced-motion、CSS 変数からのテーマ色取得）
2. Hero を `HeroField.tsx` として `client:idle` の island にし、WebGPU → Canvas 2D → 静止画の順にフォールバックさせる
3. デザイントークンを整理し、アクセントを金に一本化する。見出し用の明朝はサブセット化して `public/fonts/` に自前ホストする
4. 年表・Works・Profile・Contact を順に置き換え、使わなくなった magicui コンポーネントを削除する
5. 既存の Lighthouse CI（`.lighthouserc.json`）で LCP と TBT が悪化していないことを確認する
