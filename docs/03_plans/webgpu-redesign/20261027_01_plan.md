## 概要
コンセプトは「枯山水と円」です。旧トップの「重なる2つの円」（`LinearRotate`）を庭石に見立て、そのまわりに砂紋を引きます。七宝・青海波・円環ナビなど、ほかの模様もすべて円の組み合わせだけで作図し、余白を多くとります。


## セクション別の設計
### Hero：WebGPU の枯山水
- 全画面のフラグメントシェーダで砂紋を計算する。石の外側の線は、円柱まわりのポテンシャル流の流線 `ψ = y (1 − R² / r²)` の等高線。
- 石のまわりの同心円は、2つの円の外形からの距離 `d` と外周円までの距離 `r_c` を使い、`d / (d + r_c)` の等高線として外形から外周の円へ形を変える。外側の流線とは外周円上でつながる。
- 2つの円の重なりは斜線で塗る（旧 Hero のハッチングを継承）。円の上を金の弧が回る（旧 Hero の回転する弧を継承）。
- 読み込み時はコンパスで円を描き、砂紋が石から外へ広がる。外周円の半径が9秒周期で 1.2% 伸び縮みする。カーソルの位置には円柱をもう1つ足し、砂紋がよける。
- WebGPU 非対応時は Canvas 2D で砂紋を一度だけ計算し、弧とコンパスの描画だけを動かす。

### About：七宝の円窓
- 半径 r の円を格子点 `(i·r, j·r)`（`i + j` が偶数）に置いた七宝つなぎを、丸窓の中で4分に一回転させる。カーソルの近くの円だけ明るくする。

### Works：円環ナビ
- `works.ts` の実績を `created_at` の順に、上から時計回りに円周へ並べる。塗りの点が個人開発、輪の点が実務。円の切れ目が時系列の始まり。
- 点（`<button>`）、← → ボタン、矢印キーで選ぶと、針が回ってプレビューが円形に切り替わる。種別チップで絞り込むと、対象外の点は選べなくなる。

### Profile / Contact
- 写真はグレースケールにし、後ろに細い金の円を置く。
- Contact は青海波。光の輪が通り過ぎ、クリックした位置から波紋が広がる。

## 描画方式とフォールバック
| 要素 | 描画 | 非対応のとき | 止めるとき |
| --- | --- | --- | --- |
| Hero 枯山水 | WebGPU（全画面フラグメントシェーダ） | Canvas 2D（砂紋は静止、弧だけ動く） | 画面外、タブ非表示。`prefers-reduced-motion` では静止1フレーム |
| 七宝の円窓 | Canvas 2D | CSS の `ShippoPattern` | 画面外、`prefers-reduced-motion` |
| 円環ナビ | Canvas 2D と、点の上に重ねた `<button>` | 同じ順の一覧を SSR で出力 | 選択を切り替えた約0.7秒だけ描画 |
| 青海波 | Canvas 2D | CSS の `SeigaihaPattern` | 画面外、`prefers-reduced-motion` |

## 実装ステップ
1. 配色トークンを深緑と金に絞り、ライトテーマ用の値と `ThemeToggle` を外す
2. `src/lib/canvas/` に共通の描画ループをまとめる（DPR 上限 2、画面外とタブ非表示での停止、reduced-motion）
3. Hero を `HeroGarden.tsx` として `client:idle` の island にし、WebGPU → Canvas 2D の順にフォールバックさせる
4. `works.ts` から円環ナビを組み、`Achievements` と `AdditionalAchievements` を置き換える
5. 七宝・青海波を Canvas 化し、使わなくなった magicui コンポーネントを削除する。Lighthouse CI（`.lighthouserc.json`）で LCP と TBT を確認する
